Lockups

Filter Hero
Filter Hero

Emblem + wordmark is the default. On navy: Filter white, Hero #F24B52. On white/packaging: Filter navy, Hero #7F2328. Clear space = height of the H. Never outline, stretch, or recolor the cape mesh.

Do

  • Keep FILTER navy and HERO burgundy. Navy carries the brand; burgundy is for action only.
  • Use the angled parallelogram on Shop Now / primary ads — same clip as the site CTA.
  • Pair Ice + burgundy as a thin hairline, never as a 50/50 split.
  • On Ice chips, set type in Deep #141E30 (white on Ice fails WCAG at 2.25:1).
  • Packaging: white carton, navy/burgundy wordmark, ice mesh window, Made in USA.

Don’t

  • Don’t swap the colors, add a third brand hue, or use old ClearAir cyan #06B6D4.
  • Don’t put white type on Ice, or burgundy as a full-page background.
  • Don’t redraw, rotate, or drop-shadow the mascot. Don’t replace the cape grid with hexagons or smoke.
  • Don’t set body copy in Plus Jakarta Sans, or CTAs in rounded pills if matching the site.
  • Don’t use Signal red #F24B52 on light backgrounds — that red is navy-header only.
