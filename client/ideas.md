# Design Philosophy: Filter Hero

## Approach: Clean Swiss Modernist (cold precision)

- **Movement**: Swiss International Style & modern e-commerce minimalism
- **Brand**: Filter Hero — Precise, Effortless, Reliable
- **Colors**: Navy `#203868`, Hero `#7F2328`, Mesh `#3A66A3`, Ice `#8EB0D8`, Deep `#141E30`
- **Typography**: Plus Jakarta Sans (headings) + Manrope (body)
- **Voice**: "Find your exact filter size in seconds."
- **Signature UX**: Size finder → matched catalog → cart drawer / Stripe checkout → quote form for custom sizes

Adapted from the ClearAir storefront prototype; rebranded and extended with real cart, Stripe Checkout, and lead-gen contact.
